## Variant B: "Focus" — Notion Warm, Minimal Layout

### Design stance
Photography-first experience. Photos are the hero — minimal UI chrome, generous whitespace, light warm background like a gallery wall. Inspired by Notion's warm minimalism.

### Key choices
- Light warm theme (#ffffff bg, warm grays), no sidebar
- Top tab bar: Import | Library | Export (minimal navigation)
- 3-column spacious thumbnail grid with generous padding
- Floating action bar on photo selection
- Import: clean modal dialog with date range
- Detail view: full-bleed image with right sidebar overlay

### Trade-offs
- Strong at: photo viewing experience, approachable for casual users
- Weak at: batch operation density (fewer photos visible per screen)

### Best for
Photographers who want to enjoy the curation process and see photos beautifully
