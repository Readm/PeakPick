## Variant A: "Tool" — Linear Dark, Sidebar Layout

### Design stance
Power-user focused photo curation tool. Dense information display, keyboard-first, batch operations at your fingertips. Inspired by Linear's dark UI — the canvas recedes so photos command attention.

### Key choices
- Dark theme (#08090a bg), sidebar navigation
- 4-column thumbnail grid with score overlay (compact)
- Fixed bottom toolbar for batch operations
- Left sidebar: library tree + date range filters
- Import: full-page overlay with date picker + folder browser

### Trade-offs
- Strong at: batch operations, keyboard power users, speed
- Weak at: first-time user onboarding, spacious photo viewing

### Best for
Photographers who process hundreds of photos per session and want maximum throughput
