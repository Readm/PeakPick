# Cycle: 001-ux-first — UI 优先设计（v2）

## 目标
从用户界面出发，设计 PeakPick 的核心交互流程。出 2-3 套交互原型，导出用户工作流，再倒推后端 API。

## 界面 A：导入 / 首页
- 最近打开的文件夹列表
- "打开文件夹"按钮
- **日期范围选择器**（从 X 年 X 月 X 日到 Y 年 Y 月 Y 日，或预设选项"今天/本周/本月/本季度/全部"）
- USB 设备插入提示
- 拖拽文件夹

## 界面 B：照片网格（主界面）
- 响应式缩略图网格 + AI 评分角标
- 复选框选择模式
- **批量操作工具栏**：删除选中、**忽略/跳过选中**、标记保留
- "已忽略"视图切换（可恢复）
- 筛选栏：评分区间滑块、日期筛选、搜索
- 底部状态栏：总数 / 活跃 / 已忽略 / 已选

## 界面 C：照片详情
- 大图 + ← → 切换
- AI 评分 + 星级评分（可点击修改）
- 操作：保留 | 忽略 | 删除 | 反馈模型
- 键盘快捷键

## 设计方向（2 套原型）

| 维度 | Variant A: "Tool" | Variant B: "Focus" |
|---|---|---|
| 色系 | 暗色（Linear 风格） | 亮色/中性（Notion 风格） |
| 布局 | 左侧导航栏 + 网格主体 | 顶部导航 + 全屏网格 |
| 密度 | 紧凑（4 列缩略图） | 宽松（3 列，留白多） |
| 操作区 | 底栏固定工具栏 | 选中后浮动工具栏 |
| 适合场景 | 批量操作多的重度用户 | 优先看照片的摄影师 |
